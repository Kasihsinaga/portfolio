# Portfolio Kasih Br Sinaga

Website portfolio profesional untuk kebutuhan lamaran Banking Staff.

## Struktur
- `index.html` — halaman utama
- `assets/kasih-br-sinaga.png` — foto profil
- `CV-Kasih-Br-Sinaga-Bank-Mandiri-2026.pdf` — CV pendukung

## Deploy cepat ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload seluruh isi folder ini ke repository (bukan folder `portfolio_web`-nya).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu Save.
6. Setelah selesai, GitHub akan memberikan URL portfolio yang dapat dimasukkan ke kolom portfolio pada formulir lamaran.
